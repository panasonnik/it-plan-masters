Веб-система, яка приймає заявки працівників на несправність техніки, поєднує їх із плановим обслуговуванням і складає ІТ-адміністратору план робіт на день. Дослідницька частина — імітаційний експеримент, що порівнює чотири правила черговості (FIFO, Джексона, Сміта, динамічний пріоритет) за критерієм втрат робочого часу Z.

| Частина | Стек | Папка |
|---|---|---|
| Бекенд | Node.js 20, Express 5, PostgreSQL 18, pg без ORM | backend/ |
| Фронтенд | React 19, TypeScript, Vite | frontend/ |
| Експеримент | Node.js, без бази даних | backend/src/experiment, backend/scripts |
